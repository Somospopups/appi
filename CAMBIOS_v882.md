# APPI v882 · Usuarios unificados y Usuarios estrella

## Usuarios por persona

- APPI agrupa las garantías que pertenecen a una misma persona usando una corroboración segura con los datos disponibles en PSA: nombre, teléfono, correo, cumpleaños y domicilio/localidad.
- No se agrupa únicamente por nombre. Las coincidencias dudosas se presentan en **Revisar coincidencias** para unirlas o mantenerlas separadas.
- Las decisiones manuales de identidad quedan guardadas para las sincronizaciones posteriores.

## Productos y renovaciones

- Cada persona aparece una sola vez y puede desplegar todos los productos adquiridos.
- Cada producto muestra nombre, serie, fecha de compra y vencimiento.
- Los modelos repetidos cuentan como compras diferentes cuando tienen series diferentes.
- La misma serie repetida se deduplica para no contar dos veces el mismo equipo.
- El producto de fecha de compra más reciente determina el estado de la persona y es el único que puede generar una acción de renovación o Plan Canje.
- Los productos anteriores quedan visibles como **Equipo anterior renovado**.

## Usuarios estrella

- El nuevo botón **Usuarios estrella** muestra a quienes realizaron dos o más compras, aunque hayan elegido el mismo modelo.
- El listado estrella se ordena por cantidad de productos y luego por compra más reciente.
- Cada Usuario estrella dispone de mensajes editables para agradecer su confianza, comunicar una promoción u obsequio, volver a contactarlo o escribir un mensaje propio.
- Los mensajes se revisan antes de abrir WhatsApp y nunca se envían automáticamente.

## Compatibilidad

- Estadísticas, filtros, zonas, tarjetas, cumpleaños, reasignados, mensajes y acciones comerciales trabajan sobre personas unificadas.
- La sincronización de MI PSA y los datos en la nube conservan el detalle de cada producto.
- Se mantiene la migración automática de datos guardados por versiones anteriores.
