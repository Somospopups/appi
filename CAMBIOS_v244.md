# APPI v244 · Tu home, tu estilo

El home se vuelve un slider de filosofías: deslizás (o usás las flechas) y
cambia entre nueve estilos: Foco, Puertas, Agenda, Charla, Misiones,
Pestañas, Carrusel, Zen y Clásico (el home de siempre, con todo).

- Cada persona elige con 🎨 qué estilos quiere tener habilitados.
- El estilo elegido queda guardado; los puntitos muestran cuántos hay.
- Todos los estilos usan datos reales: próxima acción del Panel, GPS,
  parque, score, porqué y sueños.
- El botón 🎨 abre el selector de estilos; el Clásico sigue disponible
  para quien ama el tablero completo.
