# APPI v349 — Detalles del podio de cumplimiento

## Qué cambia

- El contador "✓ 8 ✗ 0 de 8" de cada tarjeta ahora tiene más aire entre los
  elementos (gap entre ✓, ✗ y "de").
- Las medallas del podio ya no repiten el número abajo: el número va solo
  dentro de la medalla (🥇🥈🥉). Se quitó el badge "1°/2°/3°" de abajo y la
  medalla quedó un poco más grande.
